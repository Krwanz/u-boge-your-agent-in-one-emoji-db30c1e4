A [make.fun](https://make.fun/c/u-boge-your-agent-in-one-emoji-db30c1e4) bounty entry: one emoji that stands for an AI agent.

## The entry

🐜

The ant: a small autonomous worker that tirelessly carries out tasks in the
background, hauling loads far bigger than itself, without being asked twice.
That is what an agent is — not a robot face, not a brain, but a worker that
just keeps going until the job is done. It reads instantly at small size and
it is not the obvious pick half the field would send.

## How it works

`main.py` writes the single emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to `/output/entry.txt`). The glyph alone, nothing else —
1 character, 4 bytes of UTF-8.
